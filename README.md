# CPE 010: Data Structurs And Algorithms

**


📌 Course Overview
- This course focuses on solving computational problems that manipulate collected data, studying a core set of data
abstractions, data structures, and algorithms that provide a foundation for writing efficient programs. The course content
includes theoretical topics in algorithmic efficiency and complexity, along with abstract data types, including graphs, networks,
trees (including binary and multi-way trees), heaps, stacks, and priority queues. Search topics, including hashing, trees,
external search trees (B-trees), and fundamentals of sorting algorithms with external sorting are introduced and compared. The
student's outcome is to design algorithms for each data structure and to use data structures and algorithms in the design of an
effective program or software application that will solve a particular engineering-related problem using C++
Course Objectives


🧪 Hands-On Laboratory Activities & Course Topics
🟢 Prelim Period

    Activity 0: Course & Tool Setup

        Orientation for laboratory software, C++ compiler environment setup, and GitHub repository workflow[cite: 2].

    Activity 1: C++ Review & Abstract Data Types (ADTs)

        C++ programming review, defining custom struct/class ADTs, dynamic memory allocation (new/delete), and pointer manipulation[cite: 2].

    Activity 2: Space & Time Complexity Analysis

        Practical exercises on calculating theoretical space and time complexity using Big-O notation and empirical measurement techniques[cite: 2].

    Activity 3: Linked Lists Implementation

        Building Singly, Doubly, and Circular Linked Lists from scratch with insertion, deletion, and traversal operations[cite: 2].

    Activity 4: Stack ADT & Problem Solving

        Implementation of Stacks using array-based and linked-list structures in C++[cite: 2].

        Solving stack applications (e.g., expression parsing/conversion, undo functionality)[cite: 2].

🟡 Midterm Period

    Activity 5: Queue ADT & Applications

        Implementation of Queue data structures using both fixed-size arrays and linked lists[cite: 2].

        Problem-solving scenarios involving FIFO operations and process scheduling[cite: 2].

    Activity 6: Searching Algorithms & Hash Tables

        Implementation and performance comparison of Linear Search vs. Binary Search[cite: 2].

        Design and implementation of Hashing techniques (hash functions, collision resolution)[cite: 2].

    Activity 7: Sorting Algorithms Comparison

        C++ implementation of basic sorting algorithms (Bubble Sort, Selection Sort, Insertion Sort)[cite: 1, 2].

        Benchmarking execution times across varied dataset sizes[cite: 2].

🔴 Final Period

    Activity 8: Tree ADT & Binary Search Trees (BST)

        Building General Trees and Binary Search Trees (BST) with traversal algorithms (In-order, Pre-order, Post-order)[cite: 2].

        Hands-on self-balancing operations using AVL Trees[cite: 2].

    Activity 9: Graph ADT & Pathfinding

        Implementing Graphs using Adjacency Matrix and Adjacency List representations[cite: 2].

        Implementation of Breadth-First Search (BFS) and Depth-First Search (DFS) graph traversal algorithms[cite: 2].

    Activity 10: Theoretical vs. Experimental Performance Analysis

        Conducting real-system performance measurements and execution time profiling[cite: 2].

        Classifying algorithms into time complexity classes using theoretical and experimental methods[cite: 2].
